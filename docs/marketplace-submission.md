The repository includes a self-hosted marketplace named `cobalt-cockpit` for GitHub installs. Its root-relative `./` source installs this plugin; function commands are registered by the hooks module, not Markdown commands. Seven bundled agents select their own model and reasoning level. There are no MCP servers, bundled credentials, runtime package launchers or extra permission grants. Runtime authentication presence checks, local processes, file reads and the opt-in session router are disclosed in README, SECURITY.md and PRIVACY.md.
